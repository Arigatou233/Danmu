# 弹幕档案库 V1.0

伊蕾娜主题 · 魔女手记风格 · 无大横幅。

## 使用

1. 解压后打开 `index.html`，或把 `index.html`、`app.js`、`avatar.png` 一起上传到 GitHub Pages 仓库根目录。
2. 点击「数据导入」，输入番剧名称、集数和来源，选择合法获取的 B站 XML 或 JSON 弹幕文件。
3. 在番剧详情中按集查看、搜索、导出 XML / JSON；在导入页面选择两个来源进行时间轴校准。
4. 当前版本使用浏览器 `localStorage` 保存数据，换设备不会同步；清理浏览器数据可能导致档案丢失。请及时导出备份。

## 已实现

- 响应式首页、番剧目录、分集详情、全文检索、统计
- XML / JSON 导入，重复弹幕过滤，来源分类
- 基于重复弹幕文本锚点的**全局偏移**自动校准（不足置信度拒绝校准）
- XML / JSON 导出，原始时间和校准映射保留
- 使用指定的九宫格第一张头像

## 限制与后续部署

- **尚未接入 B站、UP主、动画疯自动采集。** 平台数据接口、许可、登录及地区访问限制需要分别验证，不能保证全站自动抓取。
- 当前时间轴算法仅能计算**整体偏移**，无法准确处理片头变化或中途删减造成的分段错位；后续需要合法媒体素材做音视频指纹比对和分段映射。
- 当前版本不使用 Supabase，也不包含服务端定时同步；GitHub Pages 本身不能执行 Python 定时采集。
- 不提供用户投稿。数据导入只用于网站维护者在本地验证功能。
- 若要实现公开共享的自动更新，需要增加服务端采集、数据库、去重任务、审核来源匹配和定时同步；应遵守平台服务条款与适用版权要求。
